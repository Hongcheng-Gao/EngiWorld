# Environment providers

Providers create, start, stop, and reset the virtual machines used by the environment engine.
Use Docker for local evaluation; see the [quick start](../../../../README.md).
Cloud providers are configured through their provider-specific guides and environment variables.

- [Volcengine ECS](volcengine/VOLCENGINE_GUIDELINE.md)
- [Alibaba Cloud](aliyun/ALIYUN_GUIDELINE.md)
- [Pyromind](pyromind/PYROMIND_GUIDELINE.md)
