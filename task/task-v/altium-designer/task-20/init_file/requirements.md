# Draftsman Release Requirements

Create an editable native Altium Draftsman document for
`ready_to_release.PcbDoc`, using `ready_to_release.BomDoc` for BOM data.

The release document must contain:

- a fabrication drawing linked to the source board;
- a drill table and layer-stack legend;
- fabrication notes, a title block, and board dimension annotations;
- at least two assembly drawings;
- BOM data, assembly notes, revision information, and a title block.

Save the native Draftsman document as
`C:\Users\user\Desktop\release.PCBDwf`.
