JLCPCB Pick-and-Place OutJob configuration
==========================================

The OutJob output group OutputGroup1 must contain exactly one Pick-and-Place
output numbered N=1 with these fields:

  OutputType1       = Pick Place
  OutputName1       = Pick Place CSV (JLCPCB)
  OutputCategory1   = Assembly
  OutputEnabled1    = 1
  OutputEnabled1_OutputMedium1 = 1
  Columns1          = Designator,Comment,Layer,X,Y,Rotation
  Units1            = mil
  DecimalPlaces1    = 2
  Delimiter1        = ,

Columns list ordering must be exactly as above (no spaces around commas).
Use mil (imperial) units; round all coordinate values to 2 decimal places;
the field delimiter used in the resulting CSV is the literal comma.
