# 在新元件库中创建 QFN-8 封装

交付 `qfn8.lbr`。在新的 EAGLE 元件库中创建一个 QFN-8 PCB 封装：本体 5×5 mm，以原点为中心；脚距 0.5 mm；每边两个焊盘，共八个；焊盘为 0.25×0.6 mm，长边向外；从左上角 1 号焊盘开始逆时针编号。

典型焊盘布局，单位 mm：

```text
SMD 1: x=-2.35 y= 0.25 dx=0.6 dy=0.25
SMD 2: x=-2.35 y=-0.25 dx=0.6 dy=0.25
SMD 3: x=-0.25 y=-2.35 dx=0.25 dy=0.6
SMD 4: x= 0.25 y=-2.35 dx=0.25 dy=0.6
SMD 5: x= 2.35 y=-0.25 dx=0.6 dy=0.25
SMD 6: x= 2.35 y= 0.25 dx=0.6 dy=0.25
SMD 7: x= 0.25 y= 2.35 dx=0.25 dy=0.6
SMD 8: x=-0.25 y= 2.35 dx=0.25 dy=0.6
```

在 21 层 tPlace 用 WIRE 绘制丝印轮廓，并在焊盘 1 附近添加圆形或多边形标记。保存为 `qfn8.lbr`。

评分检查：恰有一个 `<package>`，恰有八个名称为 `1`–`8` 的 `<smd>`，并在 21 层至少有一个 `<wire>` 或 `<polygon>`。
