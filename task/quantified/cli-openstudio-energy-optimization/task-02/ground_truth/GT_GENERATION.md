# Ground Truth Reference

This is one feasible, non-unique reference for `quant-cli-openstudio-task-02-ubuntu`. It was rebuilt on the pinned snapshot with OpenStudio SDK/CLI 3.11.0 and the bundled EnergyPlus 25.2 engine.

The original two-zone task had four material defects: envelope R values and daylight fraction were metadata-only; both infiltration objects had all-zero coefficients; the nonzero north-axis orientation was ignored because geometry used World coordinates; and the original declared baseline window area (39.6 m2) could not fit in the two south walls. The corrected baseline preserves both 42 m2 room volumes and its 132 m2 exterior-wall quantity, changes geometry rules to Relative, distributes the declared window area across native north/south windows in both zones, adds a native daylight control in each zone, and uses effective infiltration coefficients. It was then rerun through the supplied OSW to calibrate baseline metrics.

The reference optimized IDF was generated by loading that corrected baseline through the OpenStudio 3.11 SDK, applying only constrained variables, and natively saving the IDF. `openstudio run -w /home/user/Desktop/workflow.osw` invoked EnergyPlus 25.2 to generate SQL/ERR. CSV and JSON were derived from the native standard SQLite tables. The evaluator aggregates both zones' Run Period Ideal Loads output variables, while avoiding duplicate Facility meters requested at multiple reporting frequencies.

Native verification: OpenStudio/energyplus returned 0; ERR contained 0 fatal and 0 severe errors; both-zone material, window area/azimuth, infiltration, loads, people and daylight-linked lighting appeared in native SQLite tables. As on task-01, this pinned EnergyPlus build leaves legacy `Simulations.Completed` flags FALSE despite the independent successful evidence chain, so no flag or footer is trusted alone.
