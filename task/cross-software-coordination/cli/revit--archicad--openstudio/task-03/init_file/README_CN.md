本目录包含 Task-03 诊所初始模型及完整的任务内原生工作流。Revit 2025 桥接程序保留导入的诊所外壳，并创建一处候诊室到档案室的房间边界。Archicad 27 检查并保留 Revit 原生导出文件实际包含的边界状态，不额外构造不受支持的二级关系。OpenStudio 3.10.0 及其自带的 EnergyPlus 25.1.0 生成并模拟后续能耗模型。

评测会上传已编译的桥接程序、插件清单、IFC 转换器、三个启动器、Ruby 转换程序，以及固定的初始模型、规范和天气输入，不使用可变的共享工作流辅助文件。
