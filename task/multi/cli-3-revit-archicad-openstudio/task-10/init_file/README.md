This directory contains the task-10 three-storey program-stack seed and its
task-local executable workflow. Run `run_revit_stage.ps1`,
`run_archicad_stage.ps1`, and `run_openstudio_stage.ps1` in that order on the
pinned Windows snapshot. The packaged bridge, IFC4 translator, IFC geometry
extractor, OpenStudio converter, weather file, and workflow contract are all
case-specific; no persistent instance add-in or shared `_common` runtime is
required.
