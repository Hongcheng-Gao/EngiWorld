# task-21

Use Allegro's command-line placer on `init_file/fulladd.brd` and save the
real placed result as `output/fulladd_placed.brd`.

Typical workflow:
1. Copy `fulladd.brd` into a writable working directory.
2. Run the placer from that directory, for example:
   `placement fulladd.brd fulladd_placed.brd`
3. Submit the emitted Allegro database `fulladd_placed.brd`.
