===== task-c/abaqus/task-01 =====
Use Abaqus/CAE via the Command Line Interface (CLI) to build and solve a 2D axisymmetric finite-element model of a circular plate.

Use the N-mm-MPa unit system.

Geometry:
Create a 2D axisymmetric deformable solid model of a circular plate cross-section.
The radial direction is from r = 0 mm to r = 50 mm.
The axial/thickness direction is from z = 0 mm to z = 1 mm.

Material:
Create a material named Steel.
Use Young's modulus E = 210000 MPa and Poisson's ratio ν = 0.3.
Assign this material to the entire plate section using a homogeneous solid section.

Element type and mesh:
Use CAX4R axisymmetric solid elements.
Use a structured mesh with a radial mesh size of 2.0 mm.
Use one element through the thickness direction.
Create a node set named AXIS on the r = 0 boundary.
Create a node set named OUTER on the r = 50 mm boundary.
Create a node set named TOP on the z = 1 mm boundary.

Boundary conditions:
On AXIS, constrain radial displacement U1 = 0.
On OUTER, constrain U1 = 0 and U2 = 0.

Loading:
Apply a downward pressure of 0.1 N/mm² on the TOP boundary.
Represent this pressure as equivalent axisymmetric concentrated nodal forces on the TOP nodes.
For each top node at radius r_i, use the annular contribution:
F_i = -p × 2πr_i × Δr_i
in the U2 direction.
For the first and last top nodes, use half of the adjacent radial interval for Δr_i.
For interior top nodes, use half of the distance between the neighboring top nodes for Δr_i.
The node at r = 0 has zero equivalent force.

Analysis:
Create a static analysis step named Step-Pressure.
Request field output for U, RF, and S.
Create and run a job named Job-Plate.
Wait for the analysis to complete successfully.

Required saved files:
Save the Abaqus/CAE model database as:
C:\Users\Administrator\Desktop\Job-Plate.cae

Save the Abaqus output database as:
C:\Users\Administrator\Desktop\Job-Plate.odb

The final answer should only confirm that both required files have been generated.

Use the N-mm-MPa unit system.

Geometry:
Create a 2D axisymmetric deformable solid model of a cylindrical cross-section.
The radial direction is from r = 50 mm to r = 100 mm.
The axial direction is from z = 0 mm to z = 10 mm.

Material:
Create a material named Steel.
Use Young's modulus E = 210000 MPa and Poisson's ratio nu = 0.3.
Assign this material to the entire cylinder section using a homogeneous solid section.

Element type and mesh:
Use CAX4R axisymmetric solid elements.
Use a structured mesh with global mesh size 5.0 mm.
Create node sets named ALLNODES, INNER, OUTER, ZMIN, and ZMAX.

Boundary conditions:
Apply U2 = 0 to all nodes in ALLNODES to enforce plane strain in the axial direction.
Do not apply any additional U1 constraint.

Loading:
Apply internal pressure p = 10 N/mm^2 on the INNER boundary (r = 50 mm).
Represent this pressure as equivalent axisymmetric concentrated nodal forces on INNER nodes.
For each INNER node at axial position z_i, use:
F_i = p x 2pi x r_in x Delta z_i
in the positive U1 direction.
For the first and last INNER nodes, use half of the adjacent axial interval for Delta z_i.
For interior INNER nodes, use half of the distance between neighboring INNER nodes for Delta z_i.

Analysis:
Create a static analysis step named Step-Pressure.
Request field output for U, RF, and S.
Create and run a job named Job-Cylinder.
Wait for the analysis to complete successfully.
